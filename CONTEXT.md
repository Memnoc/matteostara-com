# memnoc.dev

A personal technical portfolio whose credibility comes from matching every public claim to inspectable evidence in the linked project repositories.

## Language

**Public draft**:
The deployed, deliberately unindexed site while its launch gate remains incomplete. It may be visited directly, but it is not promoted as a finished portfolio.
_Avoid_: launched, production-ready

**Launch**:
The deliberate promotion of the site as a professional portfolio after every launch-gate condition in `PLAN.md` is verified.
_Avoid_: deploy, publish

**Built entry**:
A project presented as completed evidence of engineering ability. Its current public default branch must provide working source, a clean build, a runnable example, licensing, known limitations, and an explicit account of original work versus source material.
_Avoid_: project, experiment, work in progress

**Original Built entry**:
A Built entry whose implementation is independently authored. It may credit inspiration and prior art, but it is not an adaptation of another implementation.
_Avoid_: original idea

**Adapted and extended Built entry**:
A Built entry that began from another person's system, tutorial, or implementation and now contains substantial credited changes. Its public description must distinguish the source material from the added work.
_Avoid_: Original Built entry

**Current work**:
An unfinished project presented with its actual maturity, provenance, and public availability. Current work may demonstrate direction or active study but does not imply that the Built-entry evidence bar has been met.
_Avoid_: Built entry

**Project claim**:
A factual statement on the site about a linked project's implementation, provenance, status, or capabilities. Every Project claim must be verifiable against the linked public repository's current default branch.

**AI-assisted connector development**:
Professional work in which AI helps engineers create connectors between software systems. The term describes the development method; it does not imply that AI runs inside each connector.
_Avoid_: AI-powered connectors, systems connectors, building connectors with AI

**Applied AI study**:
Personal reading, experimentation, and writing undertaken to understand applied AI systems. It describes an active area of study, not a professional research position.
_Avoid_: AI researcher, AI research role
